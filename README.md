# Audio Announcement Stasiun Gombong

Struktur GitHub Pages:
- `index.html` — halaman utama
- `styles.css` — tampilan
- `app.js` — seluruh fungsi aplikasi, termasuk 10 narator, Teks Baku, Kereta, dan Chime

Upload **ketiga file dalam satu folder/repository**. Jangan mengubah nama file.

Aktifkan GitHub Pages dari:
Settings → Pages → Deploy from branch → pilih branch utama → folder `/root`.

Versi ini tidak membawa MP3 contoh tertanam agar file lebih ringan.
